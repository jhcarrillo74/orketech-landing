## 6. Drafts LinkedIn empresa Orketech

### Post 1 — InData / capacitación IA

Muchas empresas quieren usar IA, pero no siempre saben por dónde empezar.

En un programa aplicado para InData/BauData trabajamos con el equipo en identificar oportunidades reales de mejora de procesos usando IA, automatización, análisis de datos y herramientas prácticas.

El resultado fue concreto:

- 11 proyectos priorizados
- 5 proyectos con código Python
- 3 proyectos con uso de APIs de IA
- 6 proyectos con conexiones externas

La clave no fue “usar IA” por moda, sino conectar la tecnología con procesos reales del negocio.

En Orketech ayudamos a transformar tareas manuales y oportunidades operativas en soluciones prácticas, medibles y mantenibles.

Si tu equipo quiere detectar procesos donde la IA pueda generar impacto real, conversemos.

### Post 2 — EGLO / conciliación

Un proceso manual repetitivo puede parecer pequeño, hasta que consume horas cada ciclo y deja espacio para errores.

En un proyecto para EGLO se automatizó la conciliación de abonos de Mercado Pago / POS-ERP usando Python y procesamiento de datos.

El flujo permitió reemplazar una revisión manual propensa a errores por una solución ejecutada en minutos.

Este tipo de automatización no requiere transformar toda la empresa de una vez. Muchas veces el mayor impacto parte por detectar una tarea frecuente, acotada y dolorosa.

En Orketech ayudamos a identificar esos puntos y convertirlos en flujos automáticos útiles para la operación diaria.

### Post 3 — Banco Falabella / agente interno

Los equipos operativos suelen depender de documentos, procedimientos y conocimiento disperso para responder consultas internas.

En un POC para banca se desarrolló un chatbot/agente de IA orientado a soporte interno de operaciones, usando documentación operacional como base de conocimiento.

El piloto mostró buenos resultados cuando la información cargada estaba actualizada, confirmando una idea clave: los asistentes con IA funcionan mejor cuando se integran a procesos y fuentes confiables.

En Orketech diseñamos soluciones prácticas con IA para reducir fricción operativa, mejorar acceso a información y liberar tiempo de los equipos.
